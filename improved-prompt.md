## Improved Prompt

```
Design a comprehensive AI coding course curriculum that teaches users how to create AI agents from foundational concepts to production deployment.

# Target Audience
- Global learners across all regions and major languages worldwide
- Beginners to intermediate developers with basic programming knowledge
- Self-paced learners who can log in and immediately begin their journey

# Course Requirements

## Structure
- 6 core modules progressing from fundamentals to advanced topics
- Each lesson concludes with a quiz (5–7 questions) to reinforce understanding
- Progressive difficulty: quizzes become harder as modules advance
- Multiple learning paths (fast-track for experienced devs, standard, extended for beginners)
- Capstone project required for certification

## Core Modules
1. Introduction to AI Agents (types, components, applications)
2. Fundamentals of AI/ML + LLMs (algorithms, models, embeddings, RAG)
3. Designing & Architecting AI Agents (patterns, goals, memory, reasoning)
4. Implementing AI Agents (Python, LangChain, LlamaIndex, tool use, testing)
5. Advanced Concepts (multi-agent systems, safety, ethics, deployment, scaling)
6. Project-Based Learning (guided projects + capstone)

## Global Accessibility & Internationalization
- Support 25+ major languages at launch (see language list below)
- Full RTL support for Arabic, Hebrew, Urdu, Persian
- Code remains in English (industry standard); comments and explanations translated
- Culturally adapted examples and scenarios per region
- Purchasing Power Parity (PPP) pricing for affordability
- Mobile-first, offline-capable design for low-connectivity regions
- Regional payment methods and login providers
- WCAG 2.1 AA accessibility compliance

## Supported Languages (Phase 1)
English, Mandarin Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese (Brazilian), Russian, Japanese, German, Korean, Turkish, Vietnamese, Italian, Thai, Indonesian, Polish, Ukrainian, Dutch, Persian, Urdu, Tamil, Swahili, Hebrew

## Interactive Platform Features
- Browser-based code execution environment (Python)
- Progress tracking and bookmarking
- Discussion forums per module (multilingual)
- Peer study groups by language/region
- Adaptive quiz difficulty based on performance

## Quiz Design
- Question types: Multiple Choice, Multiple Select, Matching, Short Answer, Code Comprehension, Code Completion, Scenario-Based, Design Questions
- Immediate feedback with explanations
- Randomized question pools (3x questions per quiz for variety)
- Spaced repetition for missed questions
- Difficulty aligned with Bloom's Taxonomy progression

## E-Certificate
- Awarded upon: all quizzes passed + final exam (70%+) + capstone approved
- Three levels: Completion, Distinction, Excellence
- Contains: Learner name, course title, date, unique ID, QR verification code, skills list
- Rendered in learner's preferred language + English (dual-language option)
- Supports all scripts (Latin, Cyrillic, Arabic, Devanagari, CJK, etc.)
- Verifiable via public URL with unique certificate ID
- Shareable to LinkedIn, social media
- Format: PDF (print-ready) + PNG (social sharing)

## Final Assessment
- 40 questions (30 MCQ + 5 Short Answer + 5 Scenario/Design)
- 90-minute time limit
- 70% passing score
- Up to 3 attempts

# Output Format
Provide:
1. Complete course outline with all modules, lessons, and learning objectives
2. Quiz specifications per lesson (format, question count, sample questions)
3. E-certificate specification (content, design, verification, localization)
4. Platform requirements (technical architecture, i18n, accessibility)
5. Localization strategy (languages, translation workflow, regional adaptations)

# Constraints
- Course content must reflect 2025–2026 state of the art in AI agents
- Code examples use Python as primary language
- Frameworks covered: LangChain, LlamaIndex, CrewAI, AutoGen, LangGraph
- LLM providers: OpenAI, Anthropic, open-source (Llama, Mistral, Qwen)
- All content must be culturally neutral or regionally adapted
- Privacy compliance: GDPR, CCPA, LGPD, PIPL, POPIA
```
